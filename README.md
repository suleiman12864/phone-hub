# PHONE HUB

## Run
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Visit `http://localhost:3000`

## Admin
Visit `/admin.html`.

Development password: `phonehub-admin`

For deployment, set `ADMIN_PASSWORD` to a secure password.

The site uses placeholder images and placeholder Nigerian business contact details. Product and order data are stored separately in `data/products.json` and `data/orders.json`.
